# リコイル降下(仮題: RECOIL DIVER)詳細仕様書 v1

> ステータス: レビュー待ち(プロトタイプ未着手)。
> USP構成: ①反動移動「撃つ=動く」 × ⑤破壊物リサイクル(弾は壊して補給)

## 1. コンセプト(3秒で説明)

**「撃った反動でしか動けないガンマンが、撃ちまくって縦穴を降りていく」**

タップした方向に射撃 → 反動で逆方向に飛ぶ。下に撃てば浮き、左下に撃てば右上に跳ぶ。
弾は壊した岩の破片から補給される。最深部の着地パッドにソフトランディングでステージクリア。

## 2. 必須条件チェックリストとの適合

| 条件 | 適合 |
| --- | --- |
| 常時プレッシャー | **二重に内蔵**。(1)重力: 何もしない=加速落下→激突 (2)弾薬経済: ホバリングし続けると弾が尽きる→制御不能。「安全にゆっくり」が許されず、壊しながら降り続けることをルールが強制する |
| 物理的直感 | 反動で動く・重力で落ちる・破片が弾ける、すべて現実の物理。横に平行移動するような不自然な動きは存在しない |
| ステージ設計 | 設計された縦穴ジオメトリ=レベルデザインそのもの。地形・破壊物配置・ハザードで無限にバリエーションを作れる |
| 理不尽ゼロ | §7の公平性ルール参照(静的ハザード・弾収支バリデータ・チェックポイント・詰み防止) |
| 爽快×反射 | 連射の手応え+破片物理(matter.js)+激突ギリギリの減速。反射神経=着地・狭窄部の姿勢制御 |
| メタ接続 | 武器アンロック(操作感ごと変わる)+強化。§8参照 |

## 3. 操作(1本指)

| 操作 | 効果 |
| --- | --- |
| タッチ(押しっぱなし可) | 機体からタッチ点へ向けて射撃(連射)。**反動でその逆方向に加速** |
| 指を動かす | 照準方向がリアルタイムに変わる(ドラッグで反動方向を操る) |
| 離す | 射撃停止(自由落下に戻る) |

- 基本テク: **真下に撃つ=ブレーキ/ホバー**。左下に撃つ=右へ回避。壁の岩を撃つ=弾補給+道づくり。
- 開発用: マウス=タッチ同等、矢印キー+スペースの代替は用意しない(照準が本質のため)。

## 4. 弾薬経済(ゲームの心臓)

- 弾ストック制(マガジンなし)。初期30発、上限は強化で拡張。
- 射撃1回=1発消費(武器により異なる §8)。
- **破壊可能物(岩・鉱石)を壊すと破片が飛び散り、近くを通ると自動吸引で回収=弾+n発**。
  - 岩1個 = +3発前後(壊すのに約2発 → 純益+1以上を保証)
  - 鉱石 = +6発+コイン(メタ通貨)
- 弾切れ時: 射撃不可。落下は続く(=リスク顕在化)。ただし詰みはしない(§7-4)。
- HUDは弾数を最重要表示(残10発以下で点滅+警告音)。

## 5. 機体・ダメージ

- HP3(アーマー強化で+)。被弾間無敵1.0s。
- ダメージ源(すべて静的・可視):
  1. **高速激突**: 接地/壁衝突時の速度が閾値超過(HUDの機体色で危険速度を常時可視化: 白=安全/橙=注意/赤=激突ダメージ域)
  2. **トゲ帯**: 接触でダメージ+小さく弾き返す
  3. **溶岩溜まり**: 接触でダメージ+上向きに吹き上げられる(ハマらない)
- 激突・被弾後: 直前のチェックポイントリングから復帰 or その場継続(HPが残っていればその場)。

## 6. ステージ構造(1ステージ=1本の縦穴)

- 深さ150〜400m(タイル+ポリゴン地形)。**チェックポイントリング**を60〜80mごとに配置(通過で発光・復帰点更新)。
- 最下部の**着地パッド**に着地でクリア。着地速度が遅いほどボーナス(パーフェクト着地=ふわり接地)。
- 地形要素:
  - 壊せる岩(弾補給源)/ 鉱石・ジェム(コイン)
  - 鉄骨・硬岩(壊せない→迂回や反動での軌道調整を要求)
  - トゲ帯・溶岩溜まり(静的ハザード)
  - 狭窄部(細い通路: 微調整連射の見せ場)
  - 風の吹く区間(横に流される: 撃って抗う。風向きは矢印パーティクルで常時可視)
  - ガラス床(乗ると数瞬で割れる=足場だが留まれない。プレッシャーの句読点)

## 7. 公平性ルール(理不尽ゼロ、バリデータで機械検証)

1. ハザードは全て静的・事前可視。動く敵・時限攻撃・ランダム生成なし。
2. **弾収支バリデータ**: チェックポイント区間ごとに「区間内で入手可能な弾 ≥ 想定消費弾×2」を検証。
3. 高速激突の危険域は機体の色変化で常時警告(見えない即死なし)。
4. **詰み防止**: チェックポイント復帰時に弾を規定数(15発)まで無条件回復。弾ゼロで立ち往生しても、落下→激突→HP-1→CP復帰で必ず再開できる(罰はHPだけ)。
5. 時間制限なし(クリアタイムはボーナス加点のみ)。

## 8. 武器とメタ進行

武器=操作感そのものが変わる(リプレイ性の核)。ステージ開始時に1丁選択。

| 武器 | 反動 | 連射 | 破壊力 | 消費 | 個性 |
| --- | --- | --- | --- | --- | --- |
| マシンガン(初期) | 小 | 高 | 低 | 1発 | 微調整ホバーが得意。初心者向け |
| ショットガン | **大** | 低 | 高(拡散) | 3発 | 一撃で大きく跳ぶ+岩をまとめて砕く。上級者のショートカット御用達 |
| スナイパー | 特大 | 単発 | 貫通 | 2発 | 一直線に岩を貫通破壊+ロケットジャンプ的大移動 |

- コイン(鉱石)で: 武器アンロック / 弾上限+10 / アーマー+1 / 吸引範囲拡大。
- ショップはステージ間(SPRING DRILLのショップ画面資産を流用)。

## 9. スコア

`破壊コンボ(連続破壊で倍率↑) + 鉱石回収 + ソフトランディングボーナス(着地速度反比例) + 残HP×500 + タイムボーナス(par−実時間)×100`

## 10. 演出・音(既存資産流用+matter.js)

- 破片=matter.jsの剛体(飛散→吸引でスルスル集まる快感)。マズルフラッシュ・薬莢・トレーサー。
- 激突ヒットストップ/シェイク/赤フラッシュ、パーフェクト着地のスロー+リング(fx/juice流用)。
- 射撃音(武器別)・破壊音・回収音(コンボでピッチ上昇=既存パターン)・警告音(Web Audio合成流用)。
- アート: ダーク洞窟+ネオングロー(既存トーン)。深度で地層色が変化(terrain描画の思想を流用)。

## 11. 実装方針(プロトタイプ計画の骨子。着手前に別途実装計画を提示)

- **物理**: 機体=自前の質点物理(重力+反動力積+地形衝突は円vs.タイル/線分で十分)。**破片・薬莢のみmatter.js**(演出専用に隔離、ゲームロジックには影響させない)→ 導入リスクを最小化。
- **再利用**: core(loop/scene/viewport/input※座標付き)/fx(particles/juice)/audio一式/save(封筒形式)/ui/シーンフロー(タイトル→ステージ選択→プレイ→リザルト⇄ショップ)/深度メーターHUD/Playwright検証体制+デバッグフック。
- 地形: タイル+線分ジオメトリのハイブリッド。ステージは文字列マップ+アンカー指定(SPRING DRILL方式を拡張)。
