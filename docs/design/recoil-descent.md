## 0. Downwellから借りるもの・借りないもの

本作は「縦穴を銃で降りる」という骨格がDownwellと近い。似ることを恐れず、面白さの核を意識的に参考にする:

| Downwellの面白さの核 | 本作での扱い |
| --- | --- |
| 着地(・踏みつけ)で弾リロード=「空中が勝負、着地で一息」の呼吸 | **輸入**。足場・敵踏みつけでフルリロード |
| 敵は危険であり最高の資源(踏める敵/撃つしかない敵の色分け) | **輸入**。白=踏める/赤=踏めないの記号化ごと採用(§6) |
| 着地するとコンボが途切れる「降りたいけど降りたくない」ジレンマ | **輸入**。エアコンボ(§8) |
| ジェム経済とジェムハイ(集めると一時強化) | 形を変えて輸入(オーバードライブ §8) |
| プロシージャル生成・ローグライト構造 | **借りない**。本作は設計済みステージのクリア型+恒久メタ(Voodoo系文法) |
| 下方向射撃のみ+左右移動+ジャンプ | **借りない(最大の差別化)**。本作は移動手段が反動のみ・全方向照準。「左右移動キーが存在しない」こと自体がUSP |

差別化まとめ: **全方向反動移動 / 地形も壊せて破片が弾になる経済 / 設計ステージ+恒久強化**。

## 1. コンセプト(3秒で説明)

**「撃った反動でしか動けないガンマンが、撃ちまくって縦穴を降りていく」**

タッチした方向に射撃 → 反動で逆方向に飛ぶ。下に撃てばブレーキ、左下に撃てば右上へ。
弾は「破壊・踏みつけ・着地」で補給。最下部の着地パッドにソフトランディングでクリア。

## 2. ゲームループ(3層)

### 瞬間ループ(数秒周期)
```
撃つ(弾減/反動移動) → 岩・敵を壊す → 破片・ジェム吸引(弾+コイン)
→ その弾で姿勢制御 → (足場や敵踏みでフルリロード) → また撃つ
```
プレイヤーは常に「落下速度」「残弾」「コンボ継続」の3つを天秤にかける。

### ステージループ(1〜3分)
```
降下開始 → 区間1(ギミックA) → CP → 区間2(A+B) → CP → 最終区間
→ 着地パッドにソフトランディング=クリア → 星評価+コイン → ショップ/次へ
```
- **クリア条件 = 最下部の着地パッドに生きて着地**(パッドは深度メーターに常時表示)
- 着地の質: 高速激突(ダメージ+辛勝) / 通常 / **パーフェクト着地**(低速接地→スロー演出+ボーナス)
- **星3つは独立条件**: ①クリア ②ノーダメージ ③ジェム回収率80%以上。星合計が後半ワールドの解放ゲート

### メタループ
コイン → 強化・武器アンロック → 新ギミック/新敵のステージ → 武器の使い分けが生まれる → また潜る

## 3. 操作(1本指)

| 操作 | 効果 |
| --- | --- |
| タッチ(押しっぱなし可) | 機体からタッチ点方向へ連射。**反動で逆方向に加速** |
| ドラッグ | 照準方向をリアルタイム変更 |
| 離す | 射撃停止(自由落下) |

基本テク: 真下撃ち=ブレーキ/ホバー。斜め撃ち=横制御。敵の真上に乗る=踏みつけ。

## 4. 弾薬経済

- 弾ストック制。初期30発(強化で拡張)。射撃1回=武器ごとの消費。
- **補給手段**(すべてプレイの結果として得られる):
  1. 破壊可能物の破片吸引: 岩=+3発前後(採掘コスト2発→純益保証)、鉱石=+6発+ジェム
  2. **敵の踏みつけ: フルリロード**(+小バウンドで再浮上)
  3. **足場への着地: フルリロード**(ただしエアコンボが確定/途切れる §8)
  4. 分岐先の補給ステーション: 弾満タン+使い捨てシールド
- ホバリングし続ける・むやみに連射する→弾切れ→制御不能。「撃つ価値のある対象に撃つ」ことを経済が強制する。
- HUDは弾数が最重要表示(残10発で点滅+警告音)。

## 5. 機体・ダメージ

- HP3(アーマー強化で+)。被弾間無敵1.0s。
- ダメージ源: 高速激突(危険速度は機体色で常時警告: 白→橙→赤) / トゲ帯 / 溶岩 / **敵・敵弾(§6)**
- 被弾後: HPが残ればその場継続+無敵、HP0でチェックポイントから復帰(または残機なしならリザルト)。

## 6. 敵システム(v2追加)

### 公平性原則(理不尽ゼロと敵の両立)
1. **配置制**: 敵はステージデータで位置・種類・パターンが固定。ランダム湧き・無限湧きなし
2. **決定論パターン**: 行動は往復・周回・定点などの読めるパターン。急加速の追尾はしない
3. **飛び道具は必ず予告**(レーザーサイト表示→発射、チャージ発光)。画面外からの攻撃なし
4. **色の記号化**(Downwell式): **白系=踏める**(上から接触で倒せる+フルリロード)、**赤系=踏めない**(トゲ持ち。射撃でのみ処理)

### 敵ラインナップ(ステージ進行で1種ずつ導入)

| 敵 | 色 | 行動 | 倒し方 | ドロップ |
| --- | --- | --- | --- | --- |
| フワリ(気泡クラゲ) | 白 | その場でゆっくり上下 | 踏み or 射撃1発 | ジェム小+弾2 |
| ハネ(洞窟蛾) | 白 | 横8の字飛行(通路を塞ぐ) | 踏み or 射撃1発 | ジェム小+弾2 |
| トゲマル | 赤 | 定点 or 左右往復 | 射撃2発のみ(踏むと被弾) | ジェム中+弾4 |
| カタツム(装甲貝) | 白+殻 | 壁・天井を這う | 殻は弾く→露出面を撃つ or 踏み | ジェム中+弾4 |
| 砲台貝 | 赤 | 壁面固定。サイト表示→遅い弾 | 射撃3発(弾は撃ち消し可) | ジェム大+弾6 |
| ボス: 岩塊コア | - | 数ステージごと。コアを撃ち崩すまで着地パッドが閉鎖。砲台と装甲板の複合体 | 弱点露出サイクルを読む | 大量ジェム |

- 敵の役割: **「危険」かつ「最高の補給源」**。踏めばフルリロード+コンボ継続なので、上級者ほど敵に向かって飛ぶ。避けて素通りも常に可能(倒す義務なし)。
- 敵密度は控えめ(1画面に1〜3体)。主役はあくまで反動制御と地形。

## 7. ステージ構造と差別化3軸

- 1ステージ=深さ150〜400mの設計済み縦穴。CPリングを60〜80mごと。
- **1ステージにつき新要素(ギミック or 敵)を1つだけ導入**し、既習要素と組み合わせる。

| 軸 | バリエーション |
| --- | --- |
| ギミック軸 | 風(横流し) / ガラス床(数瞬で割れる足場) / 水没区間(浮力反転=下から撃って沈む応用問題) / 可燃ガス(撃つと連鎖爆発) / 暗闇(マズルフラッシュで照らす) / 間欠泉(上昇気流) |
| 地形軸 | 一本縦穴 → 分岐(安全な遠回り vs ジェム豊富な危険な近道) → 螺旋 → 大空洞(足場なし) → 狭窄ジグザグ |
| 目標軸(数ステージに1回) | 回収降下(遺物3つ→着地) / 護衛降下(壊れ物コンテナと共に。強反動NG=繊細な操作賞味) / ボス階(岩塊コア破壊でパッド開放) |

バイオーム(土→氷→溶岩→クリスタル→遺跡)で5ステージごとに配色・音・敵スキンが変化。

## 8. スコア・コンボ

- **エアコンボ(Downwellのジレンマを輸入)**: 足場に着地せずに連続破壊・撃破するとコンボ加算。**着地するとコンボ確定→ジェムボーナス化**。「リロードしたい(着地)/コンボを伸ばしたい(滞空)」の綱引き。
- 8コンボ以上で称賛演出+ボーナス倍率、コンボ中はジェム価値×倍率。
- **オーバードライブ**: コンボでゲージが溜まり、満タンで数秒間弾消費ゼロ(フィーバー)。
- クリアスコア = 破壊・撃破点 × コンボ + ジェム回収 + ソフトランディングボーナス + 残HP×500 + タイムボーナス(par−実時間、加点のみ)。

## 9. 強化(メタ進行)

方針: **下手でも強化を積めば通れる。上手ければ無強化で星3**。

### 恒久強化(コイン=ジェム消費)

| 強化 | 効果 | 効く場所 |
| --- | --- | --- |
| 弾倉拡張 | 上限30→+10ずつ | エアタイムの許容量 |
| アーマー | HP+1ずつ | 激突・被弾の許容量 |
| マグネット | 破片・ジェム吸引範囲拡大 | リスクを取らず回収 |
| スタビライザー | 空中姿勢の減衰向上 | 狭窄部の微調整 |
| 着地脚 | 安全着地速度の閾値UP | 荒い着地の許容 |

### 武器(アンロック+レベル) — 操作感ごと変わる核

| 武器 | 反動 | 特徴 |
| --- | --- | --- |
| マシンガン(初期) | 小 | 連射・微調整。ホバー向き |
| ショットガン | 大 | 1発で大きく跳ぶ+面で砕く。大空洞・近道向き |
| スナイパー | 特大 | 貫通破壊+ロケットジャンプ的大移動。タイムアタック用 |

武器レベルUP=破壊力UP=採掘効率UP(弾経済が楽になる)。

## 10. 演出・音

- 破片・薬莢=matter.js剛体(飛散→吸引の快感)。マズルフラッシュ・トレーサー。
- 踏みつけ=ヒットストップ+バウンス+リロード音(気持ちよさの要)。パーフェクト着地=スロー+リング。
- 敵撃破はコンボ数でピッチ上昇(既存パターン流用)。暗闇区間では射撃が照明を兼ねる(光の演出)。
- アート: ダーク洞窟+ネオン(既存トーン)、バイオームで色相変化。

## 11. 公平性ルール(バリデータで機械検証)

1. ハザード・敵は全て配置制・パターン決定論・予告付き(§6)
2. 弾収支バリデータ: CP区間ごとに「入手可能弾 ≥ 想定消費×2」
3. 激突危険速度は機体色で常時警告
4. 詰み防止: CP復帰時に弾15発まで無条件回復。罰はHPだけ
5. 時間制限なし(タイムはボーナス加点のみ)

## 12. 実装方針(プロトタイプ計画の骨子)

- 機体・敵=自前の軽量物理(質点+円衝突+タイル/線分地形)。**破片・薬莢のみmatter.js**(演出専用に隔離)。
- 再利用: core(loop/scene/viewport/input)/fx(particles/juice)/audio合成一式/save封筒形式/ui/シーンフロー(タイトル→ステージ選択→プレイ→リザルト⇄ショップ)/深度メーターHUD/Playwright検証+デバッグフック。
- ステージ=文字列マップ+敵・ギミックのアンカー指定(SPRING DRILL方式を拡張)。
