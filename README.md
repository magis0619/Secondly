# RECOIL RISER（仮）― 撃て。反動で、登れ。

**撃った反動でしか動けない**ガンマンが、下からせり上がる溶岩より先に縦穴の頂上を目指す上昇アクション(3ステージ+メタ進行)。
仕様書: `docs/design/recoil-descent.md`(v2)。※プレイフィードバックにより降下型→**上昇反転型**へ改修済み(逆Downwell)。

技術スタック: **TypeScript + HTML5 Canvas + Vite**(外部アセット・外部ライブラリゼロ。音はWeb Audio合成、絵はすべてコード描画)。iOSへはCapacitorで書き出し(`docs/ios-setup.md`)。

---

## USP

1. **移動手段が反動しかない** ― タッチした方向に射撃し、反動で逆へ飛ぶ。下を撃てば登り、斜めに撃てば横へ。移動ボタンは存在しない
2. **全方向射撃がすべて意味を持つ** ― 下=上昇 / 斜め=横移動 / **上=頭上の岩盤や敵を壊して道を開く。ただし反動で自分は溶岩側へ押し下げられる**(本作の核となるジレンマ)
3. **休憩→バースト上昇のリズム** ― 弾=燃料。足場に着地するとフルリロードできるが、溶岩は止まらない。「いつ跳ぶか」の判断が連続する

## 遊び方

| 操作 | 効果 |
| --- | --- |
| タッチ(押しっぱなし) | その方向へ連射。反動で逆方向に飛ぶ |
| ドラッグ | 照準をリアルタイム変更 |
| 離す | 射撃停止(落下) |

- **クリア = 頂上の脱出パッドに着地**。下から溶岩がせり上がり続ける(先行しすぎると追い上げる)
- 溶岩接触は即死ではなく**1ダメージ+上に打ち上げ**(リカバリー可能)。HP0で失敗
- **激突ダメージはなし**。落下の代償は「溶岩に時間を与えること」
- **白い敵=上から踏める**(倒す+フルリロード+バウンド)。**赤い敵=踏めない**(射撃のみ)
- チェックポイント通過で弾15発まで補給。星3つ: クリア/ノーダメージ/ジェム80%

## ステージ(チャンク合成式、`src/game/stages.ts`)

- **1. 大噴火イントロ**(57m, 溶岩0.85行/s): 休憩足場と基本循環
- **2. 風の煙突**(横風+細道+トゲマル, 1.05行/s)
- **3. 崩れる大空洞**(ガラス足場=乗ると割れる+岩盤天井+砲台貝, 1.2行/s)
- devバリデータ: 通行可能性 / **足場間隔≤14行**(弾タンクで登り切れる距離) / CP区間の弾収支 を機械検証

## チューニング指針(操作過負荷対策の学び)

- 世界を約35%減速(GRAVITY 26→17, TERMINAL 15→10.5)
- 1発の反動を約2倍(マシンガン rate9/impulse3.35 → **5.5/6.5**)=1発でふわっと1〜2行浮く手応え
- 横速度の減衰半減(AIR_DRAG 1.4→0.7)=斜め撃ちの横移動が効く
- すべて `src/game/config.ts` に集約

## メタ進行

ショップ: 拡張弾倉 / アーマー / ショットガン解放(大反動で大ジャンプ+面破壊、武器切替可)。セーブ: `recoilriser.save.v1`。

## 開発・実行

```bash
npm install
npm run dev      # 開発サーバ(マウスで照準・クリック=射撃)
npm run build    # 型チェック+本番ビルド(dist/)
```

iOS書き出し(Mac上): `docs/ios-setup.md` 参照。**先に本ブランチをcheckoutすること**(mainにはコードがない)。

## 検証(ヘッドレス環境)

devビルドの `window.__recoil`(`state()`/`warp(y)`/`setAmmo`/`setHp`/`world`)でPlaywrightから決定論検証。
検証済み: 底からの開始 / 溶岩上昇 / 下撃ち上昇+弾消費 / **上撃ちの押し下げ(終端速度到達)** / 溶岩接触=1ダメ+打ち上げ / 登頂クリア / 失敗 / セーブ・解放。
