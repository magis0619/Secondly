# RECOIL DIVER（仮）― 撃て。反動で、降りろ。

**撃った反動でしか動けない**ガンマンが、撃ちまくって縦穴を降りていくアクションのプロトタイプ（3ステージ+メタ進行）。
仕様書: `docs/design/recoil-descent.md`（v2。Downwellから借りた面白さと差別化の定義を含む）

技術スタック: **TypeScript + HTML5 Canvas + Vite**（外部アセット・外部ライブラリゼロ。音はWeb Audio合成、絵はすべてコード描画）。iOS へは Capacitor で書き出す（`docs/ios-setup.md`）。

> 「秒針ヒーロー」→「SPRING DRILL」からの3代目プロトタイプ。コア基盤(ループ/シーン/入力/演出/音/セーブ)は継承。旧作はgit履歴に保全(秒針=`439aa33` / ドリル=`9075f3c`)。
> 仕様書のmatter.jsは自前の軽量物理(タイル衝突+磁力吸引)で代替した — 依存ゼロを維持し、挙動は同等。

## USP

1. **移動手段が反動しかない** ― タッチした方向に射撃し、反動で逆へ飛ぶ。下を撃てばブレーキ/ホバー、斜めに撃てば横へ。左右移動ボタンは存在しない
2. **弾の経済が生存に直結** ― 弾は「岩を壊した破片」「敵を踏む(フルリロード)」「足場に着地(フルリロード)」でしか回復しない。安全にホバリングし続けると弾が尽きて墜落する=**何もしない・逃げ続けるという選択肢が構造的にない**
3. **エアコンボのジレンマ** ― 接地せず壊し続けるとコンボ倍率、でも接地しないとリロードできない(Downwellの核を輸入)

## 遊び方

| 操作 | 効果 |
| --- | --- |
| タッチ(押しっぱなし) | その方向へ連射。反動で逆方向に飛ぶ |
| ドラッグ | 照準をリアルタイム変更 |
| 離す | 射撃停止(自由落下) |

- **クリア = 最下部の着地パッドに生きて着地**。ゆっくり着地(ソフトランディング)でボーナス
- 高速で地面に激突するとダメージ。危険速度は機体の色(白→橙→赤)で常時警告
- **白い敵=上から踏める**(倒す+フルリロード+バウンド)。**赤い敵=踏めない**(射撃のみ)
- 砲台の弾は撃ち消し可能。発射前に必ずレーザーサイト予告が出る
- チェックポイント通過で弾15発まで無条件補給(詰み防止)
- 星3つ: ①クリア ②ノーダメージ ③ジェム回収80%

## 敵(配置制・決定論パターン・ランダム湧きなし)

| 敵 | 色 | 特徴 |
| --- | --- | --- |
| フワリ | 白 | ゆっくり上下浮遊。踏み台にできる最高の補給源 |
| トゲマル | 赤 | 左右パトロール。射撃2発 |
| 砲台貝 | 赤 | 壁面固定。サイト予告→遅い弾(撃ち消し可) |

## ステージ / メタ進行

- **1. 採掘孔イントロ**(81m): 基本循環+フワリ
- **2. 風の断層**(103m): 横風ゾーン+狭窄部+トゲマル
- **3. 溶岩大空洞**(97m): ガラス床+溶岩+砲台貝
- ステージは**チャンク(設計パーツ)の合成**で定義(`src/game/stages.ts`)。1行13文字の文字列でパーツを作り並べるだけで量産できる
- **ショップ**: 拡張弾倉 / アーマー / ショットガン解放(大反動で大きく跳ぶ+面で砕く。武器切替つき)
- セーブ: `recoildiver.save.v1`(ジェム・星・解放・強化を永続化)

## スコア

`破壊・撃破点 + エアコンボ(接地で確定→ジェムボーナス) + ジェム + ソフトランディング + 残HP×500 + タイムボーナス`。コンボ10でオーバードライブ(数秒間 弾消費ゼロ)。

## 公平性(devバリデータで機械検証)

- 敵・ハザードは全て配置制で事前可視。飛び道具は必ず予告付き
- 全行に通行可能な隙間(2マス以上)を保証 / CP区間ごとの弾収支(供給≥消費想定)を検証
- 時間制限なし。失敗してもジェムの半分は持ち帰り

## 開発・実行

```bash
npm install
npm run dev      # 開発サーバ(マウスで照準・クリック=射撃)
npm run build    # 型チェック+本番ビルド(dist/)
```

iOS 書き出し(Mac上): `docs/ios-setup.md` 参照。**先に本ブランチをcheckoutすること**(mainにはコードがない)。


## 検証(ヘッドレス環境)

devビルドでは `window.__recoil`(`state()` / `warp(y)` / `setAmmo` / `setHp` / `world`)が公開され、
Playwrightから決定論的な検証ができる(重力・下撃ちブレーキ・破片ドロップ・クリア・失敗・セーブ・購入を自動テスト済み)。
