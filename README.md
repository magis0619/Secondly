# Secondly ― きみは、秒針。

**「押す」と「離す」だけ**で遊べるハイパーカジュアル・アクションのプロトタイプ（1ステージ）。
プレイヤーは時計の**秒針**になり、文字盤の中心にあるコアを敵の侵攻から**60秒間**守り抜く。

技術スタック: **TypeScript + HTML5 Canvas + Vite**（外部アセット・外部ライブラリゼロ。音はWeb Audio合成、絵はすべてコード描画）。iOS へは Capacitor で書き出す（`docs/ios-setup.md`）。

---

## USP（差別化要素）

1. **「自分が時計の針」という唯一無二の操作感覚** ― 針は自動で回り続ける。狙う方向は「いつ離すか」のタイミングだけで決まる。
2. **ゼンマイを巻いて、解き放つ** ― 押している間はゼンマイを巻いて力を溜め（針が縮んで弾もかわせる）、離した瞬間に溜めた力で一薙ぎ。**溜めるほど強いが、その間も敵は迫る**。「巻くか、放つか」の2択に緊張と爽快が凝縮される。
3. **操作は2つだけ** ― タップ判定も長押し判定もない。pointerdown と pointerup がそのまま遊びになる。

## 遊び方

| 操作 | 効果 |
| --- | --- |
| **押す（ホールド）** | ゼンマイを巻く（チャージ）。針が縮み、飛んでくる弾をやり過ごせる |
| **離す** | その瞬間の針の向きへ一薙ぎ。溜め段階（Lv1/Lv2/Lv3）で射程・判定幅・威力・スコア倍率が上がる |

- 敵は外周から予告（テレグラフ）付きで湧き、中心のコアへ侵攻。コア到達で HP −1（HP3で終了）
- **Tick**（水色・菱形）: ゆっくり直進 / **Rush**（マゼンタ・三角）: 高速 / **Chime**（橙・六角）: 途中で停止して弾を連射
- Chime の弾は斬れない。**伸びた針に当たるとダメージ**、縮んでいれば通過してコアリングに無害吸収される
- 60秒生存でクリア。残りHP×1000のボーナス

## スコア

`基礎点 ×(クリット2倍)× 一薙ぎの撃破数 × 溜めティア倍率(×1/×1.5/×2) × チェーン倍率(連続撃破で最大×3)`

- **クリティカル**: 針の**先端**で仕留めると「JUST!」で2倍
- **マルチキル**: 引き付けて密集を一掃するほど跳ね上がる（3体まとめて=×3）
- **チェーン**: 2.5秒以内に撃破をつなぐと倍率上昇。被弾で途切れる

## 開発・実行

```bash
npm install
npm run dev      # 開発サーバ（ブラウザで確認。マウス/スペースキーでも操作可）
npm run build    # 型チェック+本番ビルド（dist/）
```

iOS 書き出し（Mac上）: `docs/ios-setup.md` を参照。

## ディレクトリ構成

```
src/
  core/     ループ(固定タイムステップ)・シーン遷移・入力(押す/離す)・画面/DPR・数学・乱数
  game/     ★純ロジック(描画非依存)
    config.ts   全チューニング定数の一元管理 ※バランス調整はここだけ触る
    world.ts    プレイ1回分の全状態(リトライ=new World)
    hand.ts     秒針: idle→charging→attacking→recovery
    enemies.ts / spawner.ts / combat.ts / score.ts / save.ts
  render/   Canvas描画(文字盤・敵・エフェクト・HUD)。グローは針/コア/外周のみ本物、敵は擬似グローで60fps維持
  fx/       パーティクル(固定長プール)・ヒットストップ/画面シェイク
  audio/    Web Audio合成の効果音一式(ファイルなし)
  scenes/   タイトル / プレイ / リザルト
```

- 60秒の難易度カーブ・敵パラメータ・溜めティアなどは全て `src/game/config.ts` で調整できる
- ベストスコアは localStorage（`secondly.best.v1`）に保存

## 検証（ヘッドレス環境）

devビルドでは `window.__secondly`（`world` / `skipTo(t)` / `spawn(kind, angleDeg)`）が公開され、
Playwright から任意時刻・任意配置での検証ができる。
